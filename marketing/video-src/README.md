# Sources de la vidéo LinkedIn

- `music.py` : musique originale synthétisée (120 BPM, 27,5 s), libre de droits. `python3 music.py music.wav`
- `anim.py` : animation image par image (Pillow) + assemblage ffmpeg, calée sur la musique. `python3 anim.py ../linkedin-video.mp4`
- Séquence d'ouverture : vidéo libre de droits Pixabay n° 6456 (FindingFootage), trouvée et hébergée via Orshot, dans `../stock/`.
- Démonstration : enregistrement d'écran de l'application.
